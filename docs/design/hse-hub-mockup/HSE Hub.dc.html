1HSE Hub — read layer over Asana, TrackingTime, Factorial, Samdock, HubSpot

Dark analytics console for the data screens in HSE schwarz and mint, high-contrast technical treatment, all figures in monospace so columns line up. Two layout options for the leadership dashboard; the rest are single directions built on the same shell.

Data spineSamdock / HubSpot company → contract → project → Asana tasks → TrackingTime entries → Factorial person. Every screen reads that chain; nothing is authored in the Hub in phase one. Metrics usedContracted vs. billable hours, billable vs. non-billable split, hours per user from timesheets, project record and timeline, workload per person. RolesLeadership: all teams, money visible. Team lead: own team only, capacity and approvals, no cross-team rates. Employee: own timesheet and profile. Customer portal comes in phase two. PlaceholdersFigures are plausible but invented. Hatched blocks are avatar/logo/document slots for real assets.
